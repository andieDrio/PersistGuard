# PersistGuard project baselines

- Follow the project update loop for architecture, tenant boundaries, role permissions, and implementation priorities. [PROJECT_ARCHITECTURE.md](PROJECT_ARCHITECTURE.md)
- Use the capability catalog to select detection work and validate it with observable evidence. [XDRCapabilities.md](XDRCapabilities.md)
- Read the UI standards before changing the dashboard and apply the relevant verification checks. [Standard_UIUX.md](Standard_UIUX.md)
- Use the documented entry points for setup and testing. Consult the Windows integration and rollout runbooks for changes to agent or deployment workflows. [README.md](README.md) · [Windows integration testing](docs/WINDOWS_AGENT_INTEGRATION_TESTING.md) · [Windows production rollout](docs/windows-production-rollout.md)
- At testing and implementation handoffs, offer options for the next step. Use selectable buttons when available and put the recommended option first.
- For manual GUI tests, provide the PowerShell commands and expected results so the user can run the commands in their own terminal.
